# 웨이브 디펜스 🛡️

길을 따라 몰려오는 적을 타워로 막는 작은 오락실용 전략 게임입니다. 브라우저에서 바로 실행되며, 10개 웨이브를 막아 최고 기록을 세웁니다.

- 🏹 화살 타워: 빠르고 저렴한 기본 공격
- 💣 대포 타워: 느리지만 강한 공격
- ❄️ 냉기 타워: 적을 느리게 만드는 공격
- 타워를 선택하고 맵의 빈 칸을 눌러 배치합니다. 길 위에는 지을 수 없습니다.
- 배치한 타워를 누르면 강화하거나 판매할 수 있습니다.
- 웨이브 사이에 타워를 정비하고 다음 웨이브를 시작합니다.
- 최고 도달 웨이브는 브라우저에 저장됩니다. 점수는 한 판이 끝날 때 결과로 표시됩니다.

`index.html`을 열거나 작은 오락실 로비에서 플레이할 수 있습니다.
